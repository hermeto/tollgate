# Support

- **Questions and ideas**: [GitHub Discussions](https://github.com/hermeto/tollgate/discussions).
- **Bugs, features, docs, policy proposals**: open an issue with one of the
  [issue forms](https://github.com/hermeto/tollgate/issues/new/choose).
- **Security vulnerabilities**: follow [SECURITY.md](SECURITY.md); never a public issue.

Tollgate is maintained on a best-effort basis by volunteers. There is no commercial support and no
service-level agreement. Please never share real prompts, API keys or personal data in public threads.
